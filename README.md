# PICONOMY — 피코 광고 프로젝트

> GenAI 기초 2: 멀티모달 콘텐츠 제작 과제 (과제1-2)
> AI 생성 도구만을 주된 소스로 활용해, 브랜드를 알리기 위한 10초 이내 광고형 영상을 제작하는 프로젝트입니다.

---

## 프로젝트 개요

**PICONOMY**는 실제 동물 피카(pika)의 생태를 모티브로 한 캐릭터 **피코**를 주인공으로 한 브랜드 IP입니다. 자연에서 살아남기 위한 피카의 본능(겨울 대비 먹이 저장 등)을, 자본주의 사회에서 살아남기 위한 절약·저장 본능으로 재해석한 코미디 콘셉트를 담고 있습니다.

이번 과제에서는 **"자연다큐멘터리 → 반전 코미디"** 구조의 10초 광고를 기획부터 프롬프트 설계, AI 생성, 편집까지 전 과정을 직접 설계했습니다.

| 항목 | 내용 |
|---|---|
| 브랜드 | PICONOMY (캐릭터: 피코) |
| 타겟 | MZ세대 중 절약·지출 콘텐츠를 유머로 소비하는 층 |
| 광고 목적 | 인지 — 피코 캐릭터와 세계관 첫 소개 |
| 핵심 메시지 | "세상은 넓고, 챙길 건 더 많다." |
| 영상 길이 | 10초 (씬1: 2초 / 씬2: 4초 / 씬3: 4초) |
| 화면 비율 | 16:9 (가로형) |

## 스토리 구조

다큐멘터리 톤으로 시작해, 낭만적으로 보이던 행동이 사실은 철저한 생존 전략이었음이 드러나는 반전 구조입니다.

1. **씬1 (다큐 설정, 2초)** — 피코가 여름철 꽃과 풀을 모아 바위 위에 정리해 널어놓는, 언뜻 낭만적인 다큐 장면
2. **씬2 (반전, 4초)** — 꽃을 걷어내자 그 아래 숨겨져 있던 절약 정보 뭉치(핸드폰 요금 절약법, 병원비 아끼는 법 등)가 드러남
3. **씬3 (브랜드 각인, 4초)** — 설명 없이 곧바로 로고와 슬로건으로 전환, 반전을 대사로 설명하지 않는 캐릭터 원칙 유지

## 사용한 AI 도구

| 역할 | 도구 | 비고 |
|---|---|---|
| 이미지(키프레임) | ChatGPT (GPT 이미지) | 전 씬 고정 캐릭터 묘사 문구 반복으로 일관성 확보 |
| 비디오 | Veo 3.1 Fast / Sora 2 | 씬별 특성과 실제 생성 결과 비교를 거쳐 도구 선택 (제작 중 Veo 오류 발생 시 Sora 2로 즉시 전환) |
| 오디오 | TTS | 진지한 남자 성우톤, 다큐멘터리 내레이션 |
| 편집 | 캡컷 | 컷 편집, 자막(로고+슬로건) 삽입, 오디오 싱크 |

도구 선택 이유, 프롬프트 수정 전/후 비교, 오류 대응 과정 등 제작의 전 과정은 [`PICONOMY_피코_광고_제작가이드.md`](./PICONOMY_피코_광고_제작가이드.md)에 상세히 기록되어 있습니다.
